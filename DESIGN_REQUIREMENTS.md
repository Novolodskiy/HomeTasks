# HomeTasks — Требования к мобильному дизайну

**Документ для:** Code Design / AI-дизайнер
**Цель:** скорректировать существующий макет под продуктовые и платформенные требования
**Платформы:** iOS и Android
**Язык интерфейса:** русский (на бета-этапе)

---

## 1. Контекст продукта

HomeTasks — мобильное приложение для совместного управления бытовыми задачами семьи (2-8 человек). Главные сценарии: покупки, ремонт, мероприятия детей, подарки, ветеринар, домашняя рутина.

Целевая аудитория: родители 28-50 лет, **не «гик-продуктивность»**, обычные люди. Не настраивают приложения, ожидают что «работает из коробки».

Главная фишка продукта — **низкое трение ввода**. Юзер диктует голосом → AI оформляет → задача готова. Это надо подчёркивать визуально (большая, заметная кнопка микрофона).

---

## 2. Принципы дизайна (обязательные)

1. **Простота прежде всего.** Никаких туториалов, тултипов, онбординг-флоу длиннее одного экрана. Юзер должен понять интерфейс с первого взгляда.

2. **Минимум полей.** На каждом экране показываем только то, что критично. Опциональные поля скрываем под кнопками-плашками.

3. **Тёплый, домашний тон.** Это семейное приложение, не корпоративный таск-менеджер. Цвета мягкие, скруглённые формы, дружелюбные иллюстрации в empty states (хотя empty states не делаем по требованию заказчика).

4. **Главная фишка — голос.** Кнопка микрофона на главном экране должна быть заметной и большой. Это не вторичная функция.

5. **Список, не доска.** Главный экран — простой скроллящийся список. Не kanban, не сетка, не карусели.

6. **Realtime — эффект «вместе».** Изменения от других членов семьи появляются мгновенно. Визуально подчёркиваем, что это совместное пространство (горизонтальный ряд аватаров сверху).

7. **Без свайпов.** Все действия с задачами через тап и переход в карточку. Никаких swipe-to-action на списках.

## 3. Визуальный стиль

### 3.1 Цветовая палитра

Предложение (можно скорректировать):
- **Фон**: светло-серый или белый (#FAFAFA / #FFFFFF)
- **Поверхности (карточки)**: чистый белый с лёгкой тенью
- **Акцент (CTA кнопки, активные состояния)**: спокойный синий или зелёный (#3B82F6 или #10B981)
- **Просрочено**: тёплый красный (#EF4444), не агрессивный
- **Тёмная тема**: обязательна, чёрный фон #0A0A0A, поверхности #1A1A1A

### 3.2 Типографика

- Использовать системные шрифты (SF Pro для iOS, Roboto для Android — Expo подберёт автоматически)
- Размеры:
  - Заголовки экранов: 24-28pt, средний вес
  - Основной текст: 16pt
  - Вспомогательный (даты, мелкие подписи): 13-14pt, серый цвет

### 3.3 Иконки

- Использовать **Lucide Icons** (стандарт для React Native)
- Толщина обводки 1.5-2px
- Размер по умолчанию 24×24

### 3.4 Скругления и тени

- Кнопки и карточки скруглены 12-16px
- Тени мягкие, малозаметные (`shadow-sm` уровень)
- Никаких градиентов и неоновых эффектов

---

## 4. Платформенные конвенции

### 4.1 iOS
- Стандартная нижняя навигация при необходимости
- Свайп от левого края для возврата (autobook через Expo Router)
- Поддержка Dynamic Type (увеличенный шрифт по системным настройкам)
- Тёмная и светлая темы по системе

### 4.2 Android
- Material Design 3 (последняя версия)
- Кнопка «Назад» на устройстве работает корректно
- Edge-to-edge с правильными insets

### 4.3 Универсальное
- **Safe Area** (челка / индикаторы home button) — все элементы должны быть в безопасной зоне
- Размер touch-таргетов **минимум 44×44 pt** (требование Apple HIG)
- Поддержка горизонтального положения **не нужна** (приложение только в портрете)

## 5. Описание всех экранов

Всего **9 экранов**. Для каждого ниже — обязательные элементы и поведение.

### 5.1 Sign In — Вход

**Назначение:** вход существующего юзера.

**Обязательные элементы:**
- Лого / название «HomeTasks» сверху
- Поле «Email»
- Поле «Пароль» с иконкой «глаз» (показать/скрыть)
- Кнопка «Войти» (primary CTA)
- Ссылка «Забыли пароль?» под полями
- Внизу: ссылка «Нет аккаунта? Зарегистрироваться»

**Поведение:**
- Кнопка «Войти» disabled пока поля пусты
- При ошибке — текст под полями (не модалка)

### 5.2 Sign Up — Регистрация

**Обязательные элементы:**
- Лого «HomeTasks»
- Поле «Имя» (русские буквы разрешены)
- Поле «Username» (только латиница, цифры, `_`, 3-20 символов, индикатор уникальности — зелёная галка / красный крест)
- Поле «Email»
- Поле «Пароль» с иконкой «глаз»
- Кнопка «Создать аккаунт»
- Ссылка «Уже есть аккаунт? Войти»

**Поведение:**
- Валидация полей на лету
- Уникальность username проверяется при вводе

### 5.3 Главный экран

**Назначение:** основной рабочий экран. Список задач + ряд аватаров членов семьи + кнопки создания задачи.

**Структура (сверху вниз):**

**Header — горизонтальный ряд аватаров членов семьи:**
- Каждый член: круглый аватар + имя под ним мелким текстом
- В конце ряда — кнопка-плюс «+» (добавить нового)
- Если получено приглашение — отдельная плашка «Приглашение от [имя]» с кнопками «Принять» / «Отклонить»
- Тап по своему аватару → Профиль
- Тап по чужому аватару → Семья
- Тап по «+» → Добавить члена

**Список задач (4 секции):**

1. **Сегодня** — задачи с дедлайном на сегодня + просроченные с подсветкой (тёплый красный) + задачи в статусе «Выполняю»
2. **Скоро** — дедлайн 1-5 дней
3. **Когда-то** — дедлайн >5 дней или без дедлайна
4. **Архив** — выполненные и отменённые (только за последние 7 дней)

**Карточка задачи в списке (одна строка):**
- Слева — название задачи (одна строка, с обрезкой)
- Справа — мелким серым: дедлайн (формат «сегодня», «завтра», «5 мая 18:00») и круглый аватар assignee (если назначена)
- При тапе → переход в карточку задачи

**Сортировка внутри секции:** по дедлайну от ближайшего. Без дедлайна — в конце.

**Низ экрана — две большие кнопки FAB:**
- Слева/справа кнопка **«+»** (для ручного создания)
- Большая центральная кнопка **микрофона** (для голосового создания)

Кнопка микрофона визуально доминирует — это главная фишка продукта.

**Поведение микрофона (push-to-talk):**
- Зажатие → кнопка увеличивается, меняет цвет
- Поверх экрана появляется overlay: анимированный микрофон с волнами уровня звука + распознанный текст в реальном времени
- Подсказка: «Свайп влево чтобы отменить»
- Лимит записи: 2 минуты
- Отпускание → toast «Создаю задачу...» в углу → через 2-4 секунды задача появляется в списке, toast меняется на «Задача добавлена»

**Чего НЕ должно быть:**
- Свайпов на задачах
- Названия семьи
- Иконки «Семья» (заменена рядом аватаров)
- Empty state (если задач нет — просто пустые секции с заголовками)

### 5.4 Экран создания задачи (вручную)

**Открывается:** по тапу на «+» (не микрофон).

**Структура:**
- Хедер: «×» слева, заголовок «Новая задача»
- Поле «Название» (auto-focus, обязательное)
- Поле «Описание» (опционально, многострочное)
- Кнопка-плашка «Добавить дату» → date-picker (дата + опционально время)
- Кнопка-плашка «Назначить» → список членов семьи + опция «Никому»
- Кнопки: «Прикрепить файл», «Камера», «Галерея»
- Превью прикреплённых файлов
- Кнопка «Создать» внизу

**Поведение:**
- Кнопка «Создать» disabled пока название пустое
- Тап по disabled-кнопке → подсветка поля «Название» (красная рамка)
- При закрытии с заполненными полями → подтверждение «Выйти без сохранения?»

### 5.5 Карточка задачи

**Открывается:** тапом по любой задаче в списке.

**Структура (сверху вниз):**

**Хедер:**
- Кнопка «×» слева (закрыть)

**Блок задачи:**
- Название (крупно, тап → редактирование, только для создателя)
- Описание (тап → редактирование, только для создателя)
- Плашка дедлайна (тап → date-picker, только для создателя)
- Плашка assignee с аватаром (тап → выбор, только для создателя)
- Прикрепления к задаче (только создатель добавил)
- Подпись «Создал [имя], [дата создания]»

**Кнопки действий (3 в ряд):**
- **«Выполняю»** (нажимается создатель и assignee) — переносит задачу в Сегодня
- **«Выполнено»** — отправляет в Архив
- **«Отменить»** — отправляет в Архив (отменено)

**Лента комментариев:**
- Хронологически (старые сверху, новые снизу)
- Каждый комментарий: аватар + имя + время + текст + прикрепления
- Realtime обновление
- Long-press на свой комментарий → меню «Редактировать» / «Удалить»

**Поле ввода комментария (внизу):**
- Текстовое поле с placeholder «Написать комментарий...»
- Кнопка микрофона (push-to-talk для голосового ввода комментария)
- Кнопка прикрепления (📎)
- Кнопка «Отправить»

**Чего НЕ должно быть:**
- Кнопки удаления задачи (используется «Отменить»)
- Упоминаний (@user)

### 5.6 Семья

**Открывается:** тапом по чужому аватару с главного экрана.

**Структура:**
- Хедер: «Назад», заголовок «Семья»
- Список членов семьи (вертикально):
  - Каждый: аватар + имя + username
  - У себя пометка «(вы)»
  - У других — иконка удаления справа (видна только создателю семьи)
- Кнопка «Добавить члена» (открывает экран добавления)
- Внизу: кнопка «Выйти из семьи» (для всех)

### 5.7 Добавить члена в семью

**Структура:**
- Хедер: «Назад», заголовок «Пригласить в семью»
- Поле поиска (auto-focus, placeholder «Введите username»)
- Список результатов: аватар + имя + username + кнопка «Пригласить»
- Empty state при отсутствии результатов
- Внизу: кнопка «Поделиться ссылкой на приложение» (открывает share-sheet)

### 5.8 Профиль

**Открывается:** тапом по своему аватару с главного экрана.

**Структура:**
- Хедер: «Назад», заголовок «Профиль»
- Большой аватар по центру (тап → выбор источника фото)
- Имя (тап → редактирование)
- Username (read-only, серым)
- Email (read-only) + кнопка «Сменить»
- Раздел «Безопасность»: кнопка «Сменить пароль»
- Раздел «Уведомления»: тогглы (4 штуки):
  - Назначенная задача
  - Дедлайн сегодня
  - Новый комментарий
  - Задача отмечена «Выполнено»
- Раздел «Аккаунт»: кнопки «Выйти из аккаунта», «Удалить аккаунт»
- Внизу мелким серым: версия приложения, ссылка на политику конфиденциальности

### 5.9 Восстановление пароля

**Открывается:** ссылкой «Забыли пароль?» на Sign In.

**Структура:**
- Хедер: «Назад», заголовок «Восстановление пароля»
- Текст-пояснение
- Поле «Email» (auto-focus)
- Кнопка «Отправить ссылку»
- После отправки → экран подтверждения «Проверьте почту»

## 6. Сквозные компоненты

### 6.1 Аватар
- Круглый
- Если фото нет — инициалы на цветном фоне (цвет генерируется из username хэшем)
- Размеры: 24px (в строках задач), 40px (в ряду семьи), 80px (в профиле)

### 6.2 Кнопка микрофона на главном
- Большая (56-72px)
- Иконка микрофона
- При зажатии — увеличивается, цвет меняется
- Сохранять на видном месте всегда (не прятать при скролле)

### 6.3 Плашки полей в карточке
- Скруглённый фон, мягкий
- Иконка слева, текст справа
- При тапе подсвечиваются (если редактируемые)

### 6.4 Date Picker
- Использовать нативный системный (iOS / Android)
- Модальный, появляется снизу
- Поддержка опционального времени

### 6.5 Toast уведомления
- Появляются сверху или снизу
- Длительность 2-3 секунды
- Цвет нейтральный (не красный для информации)

### 6.6 Indicator статуса задачи
- В строке задачи в списке: маленькая цветная точка слева от названия
- Цвета:
  - To Do: серый или прозрачный
  - Выполняю: синий
  - (выполненные и отменённые — в Архиве)

## 7. Анимации

Минимум, ничего лишнего:

- **Push transition** между экранами — стандартная iOS / Android
- **Модальный sheet снизу** для date picker, assignee picker
- **Кнопка микрофона** — лёгкая пульсация при зажатии
- **Список задач** — fade-in новой задачи (не slide)
- **Realtime обновления** — мягкое появление, не дёргание

---

## 8. Что НЕ должно быть в дизайне

Явные исключения, чтобы избежать:

- ❌ Категории задач, теги, приоритеты, проекты
- ❌ Календарный view
- ❌ Графики, статистика, аналитика
- ❌ Реклама, баннеры, промо
- ❌ Туториалы и onboarding-карусели
- ❌ Геймификация (уровни, очки, ачивки)
- ❌ Названия семьи на любом экране
- ❌ Свайп-действия на задачах
- ❌ Empty states с иллюстрациями (по требованию заказчика)
- ❌ Tab bar внизу (используется список с секциями)
- ❌ Сложные жесты, скрытые от пользователя
- ❌ Множественный выбор задач в списке

---

## 9. Состояния

Для каждого экрана учесть:

| Состояние | Поведение |
|---|---|
| **Loading** | Скелетоны вместо данных или системный спиннер |
| **Error (запрос упал)** | Текст с кнопкой «Повторить» |
| **Offline** | Тонкий баннер сверху «Нет интернета. Изменения сохранятся локально» |
| **Empty** | Не отображаем заглушку, показываем пустые секции с заголовками |
