# HomeTasks — Обзор документации проекта

**Что за проект:** Мобильное приложение для семейного управления бытовыми задачами. Главная фишка — голосовое создание задач с AI-обработкой.

**Этап:** Подготовка к разработке. PRD, архитектура и требования к дизайну согласованы. Ждём настройку Jira и MCP-сервера от Product Owner. После — начинаем декомпозицию на эпики и задачи.

## Поиск в истории прошлых сессий

Если нужно найти что-то из предыдущих обсуждений, используйте фразы:
- «Найди в логах ...»
- «Мы это обсуждали ...»
- «Помнишь как мы говорили про ...»

Где искать:
- **DECISIONS_LOG.md** — все ключевые решения с альтернативами
- **`~/.claude/projects/-Users-user-Desktop-Tasks/*.jsonl`** — полная история всех сессий (автоматически сохраняется Claude Code)

Подробный алгоритм — в USER_CONTEXT.md, раздел 7.

**Ключевые роли:**
- **Product Owner / Тестировщик** — Дмитрий Новолодский
- **Системный аналитик** — Claude (System Analyst), создаёт эпики и задачи в Jira, готовит ТЗ, координирует разработку
- **Дизайнер** — внешний AI-инструмент Code Design (макеты по DESIGN_REQUIREMENTS.md)
- **Разработчики** — AI-агенты (Agent-1, Agent-2 при необходимости), берут задачи из Jira

## Где мы сейчас

✅ Согласовано:
- Продуктовый скоуп MVP, 9 экранов, бизнес-правила
- Архитектура: Expo + Supabase, монорепо, окружения «прод» и «стейдж»
- Голосовая обработка через Edge Function (для безопасности AI-ключей)
- Стратегия запуска: бета на русском бесплатно → глобальный paid релиз
- Jira как таск-трекер, MCP для интеграции
- Работа с одним агентом-разработчиком на старте
- Никакого Confluence — документы в репозитории
- Имя: HomeTasks (требует проверки доступности доменов и App Store до подачи в Apple Developer)

⏳ В работе у Product Owner:
- Дизайн-макет в Code Design (передан DESIGN_REQUIREMENTS.md)
- Регистрация Jira аккаунта + MCP-сервер
- Открытие Apple Developer аккаунта (срочно — проверка занимает до 2 недель)

📝 Следующие шаги для системного аналитика (Claude):
1. Дождаться готовой Jira (URL workspace, project key, API tokens)
2. Создать пользователей в Jira (claude-analyst, agent-1)
3. Создать тикет HT-1: Agent Communication Hub
4. Настроить Jira Automation Rules (email-уведомления)
5. Декомпозировать backlog на эпики (8 эпиков, ~50-70 задач)
6. По каждому эпику написать системную аналитику в `docs/epics/XX-name.md`
7. Подготовить детальные ТЗ + критерии тестирования для каждой задачи
8. Когда придёт макет — добавить UI-задачи

## Эпики (предварительный список)

1. **Auth и регистрация** — Sign In, Sign Up, Forgot Password
2. **Семьи и инвайты** — создание семьи, добавление членов, выход
3. **Задачи: ручное создание и список** — главный экран, секции, ручное создание задачи
4. **Задачи: голосовое создание** — push-to-talk, Edge Function с Whisper и Claude
5. **Карточка задачи + комментарии** — детальный экран, realtime-комментарии, голосовой ввод комментариев
6. **Прикрепления** — фото и файлы к задачам и комментариям
7. **Push-уведомления** — Expo Notifications, серверные триггеры
8. **Оффлайн-режим, полировка, подготовка беты** — локальный кеш, очередь мутаций, бета-релиз

## Стек (зафиксирован)

**Frontend:** Expo (React Native) + TypeScript + NativeWind + Expo Router + TanStack Query + Expo SQLite

**Backend:** Supabase (Postgres + Auth + Storage + Realtime + Edge Functions)

**AI:** OpenAI Whisper (голос → текст) + Anthropic Claude Haiku 4.5 (текст → структурированная задача), оба вызываются из Edge Function

**Инфраструктура:** GitHub (репозиторий), Jira (задачи), EAS Build (сборки), TestFlight + Internal Testing (бета), App Store + Google Play (прод), RevenueCat (для будущих платежей)
